## 最小架构升级（2026-10-11 至 12，v0.9.0）

根据用户确认的最小范围，保留 Python / FastAPI / NiceGUI / LangGraph，增加 Docker Compose 的 Web、独立 Worker、PostgreSQL/pgvector 与 Redis。PostgreSQL 适配保持本地 SQLite 兼容，关键写事务使用 advisory lock；Redis Streams 仅作通知，事务 Outbox 与运行租约以 SQL 为准。原文检索采用中文双字词和英文词，未实现语义向量检索。新增文档入口、只读工具、原文位置与完整性核验、依赖任务并行，以及 OpenTelemetry / SQL 调用追踪。

首次两个新测试的失败来自错误预期：原文篡改后旧报告读取应被 409 拒绝；审批的版本与指纹位于 content，并使用 /decision 接口。原有六项串行派发测试改为显式 concurrency=1，另建 concurrency=2 的整批预算、并发中暂停/停止和恢复检查，未降低控制或幂等约束。真实子进程测试使用本机合成模型 HTTP 服务，核验审批状态跨 Worker 重启保留且规划不重复。

浏览器使用已有 Playwright 单进程 Edge 方案。截图复核发现精确字段解析器只支持扶摇路径，补齐 $.excerpts[index].text 后复验；另补等待资料弹窗关闭与输入事件提交，避免探针过早发送。最终浏览器 10 项通过，发布分类回归 23 项通过。Linux 镜像与四服务健康检查实际执行；未调用真实模型或金融接口。保留用户 .env、PyCharm 配置和默认 SQLite 历史，Docker 使用新数据库卷。详见 [部署与验证范围](minimal-deployment.md)。
