日期：2026-10-11。第四批已实现本地浏览器工作台，Python 技术栈和现有数据库沿用。第五批上下文压缩、长期记忆、报告导出及最终公开交付仍待实施。

## 已实现的操作

- 桌面三栏：研究空间、研究任务、研究成果；宽度不足 1180px 时切换为研究/任务/成果标签页。390px 手机视口无页面横向溢出，证据抽屉可关闭。
- 新建空间、输入目标、设置工具/模型/token/总时限预算、选择历史运行。显示供应商费用未知及配置/验证状态。
- 计划、前置依赖、实际任务结果、工具尝试、模型用量和持久化事件。进度根据已完成/失败/受阻任务计数，等待规划时仅显示加载状态。
- 暂停、继续、停止、可恢复失败入口；预算审批的批准、拒绝和修改由服务端验证。
- 只在暂停或等待审批且当前租约结束后编辑未派发任务：标题、参数、前置依赖及移除。校验白名单、参数和引用，不能修改或删除已派发任务；保存增加计划版本、使旧审批失效并保持暂停。
- 报告区展示事实、推断、不确定信息与缺口；校验失败阻止核心报告展示。指标关联计算公式和输入证据，财务表关联原始字段。
- 价格图表使用已通过原始响应/映射校验的历史收盘价，可缩放；不同复权分别成图，缺失观测保留为空。点击真实数据点打开对应 `source_index` 的原始 `close_price`。
- 证据抽屉展示源、质量、单位、数据/获取时点、原始值、响应、字段映射和内容指纹。浏览器上海时间显示；格式化舍入只影响展示。

## 实时与恢复

NiceGUI 页面的后台订阅读取当前会话的持久化 `run_events`，经 Socket.IO/WebSocket 更新组件。每批保存事件游标与当前线程/运行 ID 到 `sessionStorage`；不保存凭据。重连和刷新重新读取所属会话的数据库快照，再补回游标之后的事件。浏览器连接不承担研究生命周期，断线期间研究仍由 Harness 控制。

新增接口：

| 接口 | 用途 |
| --- | --- |
| `GET /api/runs/{id}/snapshot` | 运行、任务、证据、指标、模型用量及事件游标 |
| `PUT /api/runs/{id}/plan` | 带版本和计划指纹的完整计划更新；需要 Cookie 与 CSRF |
| `GET /api/runs/{id}/events/stream?after=...` | SSE：snapshot、真实 run-event、terminal complete；支持 Last-Event-ID |

SSE 的事件 ID 为数据库事件 ID，快照不覆盖重放游标；超前游标明确 reset。所有接口均验证所属会话，非法游标拒绝。订阅只读，不触发模型或金融调用。

修改计划后的旧 LangGraph 中断不能继续授权新计划。恢复时比较持久化计划版本，版本变化则从已保存计划重新进入调度，调用账本复用已完成工作；旧中断索引和参数不被复用。

## 当前限制

计划编辑器修改/移除已有未派发任务；新增任务可通过完整计划 API，尚无界面内添加任务向导。多个同名标的需要修改未派发搜索任务或用明确代码新建研究，尚无专用消歧卡。

报告是本地初版产物，可查看 JSON；多版本、正式导出、追问关联、上下文压缩和长期记忆属于第五批。iFinD 未配置，未声称完成真实接入。匿名 Cookie、单实例 SQLite、容器/公开 URL/远程仓库等边界见 known-limitations.md。
