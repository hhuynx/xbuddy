## 使用与边界

在 PyCharm 停止旧进程，再运行原来的 `server.main` 配置；访问 `http://127.0.0.1:8080`。新建研究后查询数据，保存记录可展开证据与原始响应。API 文档为 `/api/docs`，完整步骤见 README。

默认数据库 `data/xbuddy.sqlite3`，保留此目录和浏览器会话 Cookie，重启不会清空研究。不要将本地数据库、`.env`、市场原始响应或测试浏览器资料提交仓库。

本批财务计算仅采用明确年报利润表；季度报告期的累计/单季口径尚未确认，拒绝计算。资产负债表/现金流路由实现了契约，但本次真实集成验收限于利润表。工具 `verified_scope` 显示最近验证的接口与口径，不保证所有参数和财报类型都有权限。

iFinD 的 SDK 桥接和白名单用构造 MCP 做过验证，实际端点/账号尚未配置；通用返回在字段、时间和单位映射前标为 unverified，不能参加金融计算。模型 Planner、审批、中断调度、完整报告、压缩和长期记忆尚未作为产品流程接入。公开 URL、源码远程仓库、生产身份认证与部署恢复仍属后续工作。
