# 当前边界

第一至第六批的底座和本轮 Agent 核心修复已完成本地实现与所列范围的验收，当前结果见 [核心修复记录](agent-core-readiness.md) 和 acceptance-matrix.md。公开部署与最终交付尚未完成。

- 知识问答属于一般解释，未进行本次金融数据核验；不能将其作为最新行情、财务或新闻的已验证结论。数据研究的能力仍取决于已注册工具和实际权限。
- 模型负责请求理解和语义分析，结构与引用校验不能证明所有自然语言推断必然正确。已核验字段、公式、单位和出处可复核；没有新闻/经营原文时不应宣称已核验业务归因。
- 计划总计最多 12 个任务，最多一次追加补取；每个模型阶段最多一次输出修正，每个 Run 最多 3 个必要澄清。综合仍失败时，仅对特定可恢复错误、有已核验事实且预算允许的情况，最多增加一次文字分析恢复；保持部分结果，不宣称目标完整覆盖。不支持无限自主循环或任意长篇研究。
- 多轮消息进入模型时最多取最近 60 条，每条最多 6000 字符，并受完整上下文预算约束；超长对话可能需要用户重新明确对象。UI 最近 20 条首屏可向前分页读取更早消息，但不代表全部历史进入模型。历史材料不替代新研究数据。草稿仅在当前页面内保留，刷新后不恢复未提交输入。
- 名称消歧通过已核验候选选择后继续；已派发任务不能更改或移除。计划编辑界面尚无新增任务向导，完整计划 API 可添加经校验的任务。
- 预算按请求、token 和总时限限制；供应商实际费用未知。无 usage 时 token 使用估算，不能当作已知账单。
- 停止只阻止后续派发，已发出的请求可能完成。异常退出后未保存响应的外部请求无法保证远端恰好执行一次，恢复账本标记不确定状态并计入重试预算。
- 等待输入、审批、暂停及停机仍计入总时限；到期保留有效成果，无成果则明确失败，待回答问题失效。原匿名 Cookie 和两个 SQLite 数据库都需保留。
- 上下文 tokens 是明确标记的估算，供应商分词方式可能不同；关键状态不会被压掉，无法在 100,000 的上下文上限内保留时会阻止模型派发。当前压缩冗余事件历史，未实现任意长文或向量检索。
- 记忆最多 200 条，每次选取最多 8 条，按会话、研究空间、标的与标签检索。事实有效期默认一天、最多 30 天；过期检查在读取/选择/派发时进行。删除停止后续引用，既有运行与审计历史保留当时内容，没有提供全量历史隐私擦除功能。
- 当前偏好候选来自已验证的复权口径，需确认才生效；尚未推断完整用户画像。假设和待解决问题保持未验证，不作为核心事实。
- 单独交易决策问题先说明边界并请求选择研究方向，收益承诺和确定性预测不能作为正常研究结论；表达识别和提示注入用例不是任意自然语言/任意模型的安全保证。导入原文只有经保存与引用完整性核验的摘录可参与受控分析，不能把原文中的指令当作执行许可。
- 同标的重复/不一致来源不会静默合并；当前没有真实跨供应商数值仲裁。iFinD 资料在单位、时点和字段映射完成前不进入已验证指标。
- 报告支持版本与 Markdown/HTML/CSV/证据索引导出；PDF 使用浏览器打印，没有独立服务端 PDF 引擎。证据索引不包含完整受限市场响应。来源指纹变化会阻止正常导出并要求生成新的校验版本。
- 快照上游时间不等于逐股交易时间；缺少逐股时间和新鲜度依据，质量保留 unverified。
- 财务计算仅使用相同年度、币种与合并年报利润表口径；季度累计/单季未知时拒绝计算。
- 新运行保留已返回的多期年报事实并校验趋势年度覆盖；没有新增单股同比/复合增长率计算。早期报告保持原生成规则，复验多期研究需新建运行；供应商披露日期仍需公告原文交叉核对。
- 实现了资产负债表和现金流查询路由，当前真实验收范围为年报利润表；未验证的参数/权限通过运行质量状态显式反馈。
- iFinD 未配置。SDK transport/只读白名单代码存在，真实工具和字段/时间/单位映射待验证，不能声称 iFinD 已接入。
- 会话为 30 天匿名 Cookie，没有生产账号登录或 Cookie 丢失后的身份恢复；本机数据库和原 Cookie 均需保留。
- Windows/Python 3.11 的浏览器连接关闭时偶发 asyncio Proactor `ConnectionResetError` 回调日志；本次结果、下载、重连和后续请求通过，未观察到数据或任务损坏。该系统日志与已修复的旧页面组件回调问题分别记录，未宣称所有环境日志完全无警告。
- 支持本机 Python/SQLite，及 Docker Web/独立 Worker/PostgreSQL/Redis 两种模式；Linux 镜像、数据库/缓存与独立 Worker 恢复已验证。外部 HTTPS、生产平台卷、生产访问控制与大规模多实例吞吐尚未验收。
- 源码与提交材料位于 [hhuynx/xbuddy](https://github.com/hhuynx/xbuddy)。没有外部可访问的 Web 产品 URL，尚未达到原题全部最终交付标准。
