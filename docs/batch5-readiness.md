## 已完成能力

| 能力 | 实现与边界 |
| --- | --- |
| 分层上下文 | 目标/约束、完整计划与任务、审批、证据目录/计算引用、缺口、历史报告和选中的记忆；完整工具响应保留在原证据存储，字段切片接口支持按 ID 分页 |
| 真实压缩 | 超出上下文输入预算且确实减小体积时，将冗余事件历史替换为结构化摘要；关键状态原样保留，不新增模型调用 |
| 压缩观测 | 原文与发送内容、摘要、来源 Run/事件 ID/范围、完整内容指纹、前后估算与触发原因；真实持久化 `context.compressed` 事件 |
| 记忆生命周期 | 保存、检索、修正、删除、过期；跨研究或研究空间范围、标的/标签筛选；每次研究冻结并展示实际使用版本 |
| 记忆可信度 | 明确偏好、已验证历史事实、未验证假设和待解决问题分开；推断偏好候选仅在内容指纹/版本匹配的用户确认后生效 |
| 研究事实 | 仅从已校验报告的事实结论保存，绑定证据/原始字段、单位/口径、报告版本、历史时点；默认一天、最多 30 天有效期 |
| 版本报告 | 初版及追加版本保持不可变，版本校验采用并发版本比较；导出前重新核对原始字段、内容指纹和确定性公式 |
| 导出 | Markdown、独立 HTML（含价格 SVG 与财务表）、保留原值/单位/引用的 CSV、证据索引 JSON；浏览器打印到 PDF |
| 关联追问 | 创建同研究空间下的新 Run，绑定具体前次报告版本；以历史报告作参考，当前核心结论必须使用新运行重新取得的证据 |
| 产品入口 | 长期记忆管理、事实保存、上下文记录、版本切换/追加、导出、打印、关联追问；导航打开实际关联版本，刷新保留选择 |

## 实际验证

自动检查最终 **82 passed**；第五批新增 **18 项**。构造模型与 HTTP 响应用于可重复验证：

- 记忆实际进入模型上下文；修正后使用新版本；删除后新运行不再选择；历史使用记录保留。
- 推断候选等待确认、错误内容指纹/旧版本/重复决定拒绝；修正候选使旧确认失效；拒绝候选不被引用。
- 记忆范围、标的、标签、过期与时区输入；假设始终保留未验证状态。
- 事实绑定原报告结论与时点，不接受无依据事实、推断转事实或超期事实。
- 关联追问实际重新查询，使用不同的调用/证据记录；真实事件历史压缩后保留全部关键状态，原文按 ID 可读取。
- 上下文预算和模型调用预算连续审批不会误用旧恢复值；第一项批准后第二项仍能阻止模型/工具派发。
- 上下文内容改动会校验失败；按需证据字段切片限制字段、条数与原始索引。
- 追加报告版本不重新调用金融源；旧版本不变化；CSV 数值和引用准确，HTML 转义及 CSV 公式注入处理通过。
- 原始证据指纹变化阻止正常导出和事实保存，重新校验的失败版本不包含核心结论。
- 新资源继续按会话隔离；写入要求 CSRF。

`compileall` 通过，`pip check` 无依赖冲突。`smoke_ui.py` 验证当前 batch5_knowledge_artifacts 页面、健康、API/OpenAPI 与 Socket.IO 握手。

## 如何验收

```powershell
& .\.venv\Scripts\python.exe -m pytest tests -q
& .\.venv\Scripts\python.exe scripts\smoke_ui.py
& .\.venv\Scripts\python.exe -m server.main
```

浏览器访问本机页面，在左栏保存明确研究偏好；完成研究后点开事实依据并保存历史事实。提出偏好候选后先观察等待确认状态，再确认。右栏追加报告版本、切换版本、下载四种文件或打印为 PDF；发起关联追问，检查新 Run 的证据 ID、实际记忆及上下文记录。删除记忆后创建新研究，确认旧版本没有被注入。

新增 API：`/api/memories`（CRUD/versions/decision）、`/api/runs/{id}/memory-proposals`、`/api/runs/{id}/context` 与 `/context/entries`、`/api/context/{id}`、`/api/evidence/{id}/slice`、`/api/runs/{id}/reports`、`/api/runs/{id}/followups`、`/api/artifacts/{id}/export` 与 `/print`。所有接口保留匿名会话资源隔离和写入审批边界；具体输入见本机 `/api/docs`。
